# HTML, CSS & JS Basics

A practice page built from scratch during a hands-on Domestika course, as a UX/UI designer learning to code to better communicate with development teams.

🔗 **[View live](https://garyalua.github.io/domestika-html-css-js-basics/)**

## What it includes

- Semantic HTML
- SCSS organized by component (nav, sections, modals) with global variables and responsive nesting
- Vanilla JavaScript: responsive menu, hover microinteractions, and a code-preview modal
- Built with Parcel

## Running it locally

```bash
npm install
npm run start
```
